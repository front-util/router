# Архитектура @front-utils/router

Этот документ описывает внутреннее устройство роутера для облегчения работы AI-агентов.

## Основные компоненты

1.  **HashNavigation (`src/core/hashNavigation.ts`)**:
    *   Низкоуровневый API, оборачивающий Browser History API.
    *   Управляет списком записей истории (`entries`), текущей записью (`currentEntry`) и возможностью навигации назад/вперед.
    *   Использует сигналы для реактивного обновления состояния.
    *   Слушает событие `hashchange` и синхронизирует состояние.

2.  **HashRouter (`src/core/hashRouter.ts`)**:
    *   Высокоуровневая абстракция над `HashNavigation`.
    *   Добавляет понятие "маршрутов" (routes) и "шаблонов" (patterns).
    *   Позволяет проверять существование страницы (`hasPage`).
    *   Предоставляет вычисляемые сигналы (`computed`) для `params` и `query`.

3.  **ClientRouter (`src/react/ClientRouter.tsx`)**:
    *   React-компонент для декларативного роутинга.
    *   Подписывается на изменения `hashRouter`.
    *   Автоматически извлекает параметры из URL и передает их в компоненты страниц как пропсы.

## Поток данных (Data Flow)

1.  Пользователь вызывает `hashRouter.navigate('path')` или меняет хеш в URL вручную.
2.  `HashNavigation` ловит изменение или обновляет состояние через History API.
3.  Сигнал `currentEntry` в `HashNavigation` обновляется.
4.  `HashRouter` через `computed` обновляет `params` и `query`, основываясь на новом хеше.
5.  `ClientRouter` (React) реагирует на изменение сигналов и перерисовывает нужный компонент.

## Ключевые паттерны

-   **Сигналы**: Вся реактивность построена на `@preact/signals`. Это позволяет обновлять только те части UI, которые действительно зависят от текущего маршрута.
-   **Фабрики**: Объекты создаются через функции-фабрики (`createHashRouter`, `createHashNavigation`), что упрощает тестирование и изоляцию состояния.
-   **Параметризованные маршруты**: Поддерживаются паттерны вида `users/:id`. Парсинг реализован в `src/helpers.ts`.

## Важные файлы
- `src/types.ts`: Единственный источник правды для интерфейсов.
- `src/helpers.ts`: Чистые функции для работы со строками URL и маппинга маршрутов.
