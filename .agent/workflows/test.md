---
description: Запуск тестов и покрытие
---

Этот воркфлоу описывает работу с тестами в проекте.

1. Запусти тесты разово:
```bash
bun run test
```

2. Запусти тесты в режиме наблюдения во время разработки:
```bash
bun run test:watch
```

3. Проверь покрытие тестами:
```bash
bun run test:coverage
```

4. Все новые функции ДОЛЖНЫ покрываться тестами в `src/__tests__/`.
5. При изменении логики в `src/core/`, обязательно запусти все тесты, так как это ядро системы.
