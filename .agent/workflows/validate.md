---
description: Полная валидация проекта (lint, types, tests)
---

Этот воркфлоу запускает полную проверку проекта, чтобы гарантировать его работоспособность и соответствие стандартам.

// turbo
1. Запусти скрипт валидации:
```bash
bun run validate
```

2. Если возникли ошибки линтинга, исправь их автоматически:
```bash
bun run check-lint --fix
```

3. Если возникли ошибки типов, проанализируй и исправь их в соответствующих файлах.

4. Если тесты упали, изучи вывод Vitest и исправь логику или обнови тесты (если дизайн намеренно изменился).

5. Повтори запуск `bun run validate`, пока проект не станет зеленым.
