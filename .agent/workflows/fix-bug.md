---
description: Исправление бага (Workflow для отладки)
---

Этот воркфлоу описывает процесс поиска и исправления ошибок в проекте.

1. Проанализируй описание бага или сообщение об ошибке.

2. Если баг связан с взаимодействием роутера с хостом/историей (страницы-хосты, auth-тоггл, back/forward между страницами хоста), воспроизведи его e2e-спекой:
   - Создай/дополни spec-файл в `apps/e2e/e2e/`, используя хелперы из `apps/e2e/e2e/utils.ts`.
   - Запусти: `npm run test:e2e` (или `npx playwright test <spec>` из `apps/e2e`).
   - Убедись, что тест падает (воспроизводит баг).
   - После исправления запусти весь e2e-набор.

3. Если баг касается чистой логики строк/роутов (`packages/router/src/helpers.ts`) — пиши тесты в `packages/router/src/__tests__/helpers.test.ts`.

4. Для багов ядра (`packages/router/src/core`) можно добавить unit-тест, но помни о моках браузера в `beforeEach` (мок `window.location`/`window.history`; синглтоны `hashRouter`/`hashNavigation` общие для файла).

5. После подтверждения бага внеси исправления в соответствующий файл в `packages/router/src/`.

6. Запусти тесты повторно, чтобы убедиться в исправлении:
```bash
npm run test
npm run test:e2e
```

7. Запусти полную валидацию перед коммитом:
```bash
npm run validate
```
