description: Исправление бага (Workflow для отладки)
---

Этот воркфлоу описывает процесс поиска и исправления ошибок в проекте.

// turbo
1. Проанализируй описание бага или сообщение об ошибке.
   
2. Если баг связан с логикой роутинга (`src/core`), найди соответствующий тест в `src/__tests__/hashRouter.test.ts` или `src/__tests__/hashNavigation.test.ts`.

3. Создай НОВЫЙ тест (или блок `it`), который воспроизводит описанный баг. 
   **Важно**: Помни о моках браузера в `beforeEach`.

4. Запусти тесты, чтобы убедиться, что они падают:
```bash
bun run test
```

5. После подтверждения бага, внеси исправления в соответствующий файл в `src/`.

6. Запусти тесты повторно, чтобы убедиться в исправлении.

7. Запусти полную валидацию перед коммитом:
```bash
bun run validate
```
