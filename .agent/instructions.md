# Инструкции для AI-агента в проекте @front-utils/router

Этот проект представляет собой легковесный hash-роутер на основе сигналов (@preact/signals).

## Стек технологий
- **Runtime**: Bun
- **Язык**: TypeScript (строгая типизация)
- **Сборка**: Rspack, tsc (для типов)
- **Тестирование**: Vitest
- **Управление состоянием**: @preact/signals

## Основные правила
1. **Типизация**: Всегда используй строгую типизацию. Избегай `any`. Экспортируй интерфейсы из `src/types.ts`.
2. **Производительность**: Роутер должен быть максимально быстрым. Минимизируй количество подписок и перерисовок.
3. **Валидация**: Перед завершением задачи ОБЯЗАТЕЛЬНО запусти `bun run validate`. Это проверит линтинг, типы и тесты.
4. **Стиль кода**: Следуй правилам ESLint. Используй функциональный стиль.

## Структура проекта
- `src/core/`: Ядро роутера (`hashNavigation.ts`, `hashRouter.ts`).
- `src/react/`: Bindings для React.
- `src/helpers.ts`: Вспомогательные функции.
- `src/types.ts`: Общие типы и интерфейсы.
- `examples/`: Примеры использования.

## Команды
- `bun run check-lint`: Проверка линтером.
- `bun run check-types`: Проверка типов.
- `bun run test`: Запуск тестов.
- `bun run validate`: Полная проверка проекта (lint + types + tests).
- `bun run build`: Сборка проекта.

## Работа с багами
Используй воркфлоу `/fix-bug`. Обязательно сначала воспроизведи баг через тест в `src/__tests__/`, учитывая специфику моков браузера (`window.location`, `window.history`), так как проект сильно зависит от окружения DOM.
